# English Security Summary

**Threat:** A targeted phishing campaign impersonating the internal IT support team using spoofed sender details to trick employees into visiting a phishing website.

**Affected Asset:** Municipal user identities, employee endpoints, and internal municipal systems.

**Main Impact:** Potential unauthorized access to sensitive municipal systems and personal data if login credentials were disclosed during the link interaction.

**Top Control:** CIS Control 6 (Access Control Management) by enforcing mandatory Multi-Factor Authentication (MFA) across all external system access points.

**Key Limitation:** Technical filters cannot block all phishing emails, leaving a residual risk related to human interaction that requires reporting procedures and staff awareness.
